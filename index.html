Обзор JavaScript

JavaScript - мультипарадигменный язык программирования, стандартизированный как ECMAScript. Изначально создан для браузеров, сейчас используется и на сервере (Node.js, Deno, Bun).

Ключевые особенности

  • Динамическая типизация.
  • Прототипное наследование.
  • Функции - объекты первого класса.
  • Однопоточность и Event Loop для асинхронности.
  • JIT-компиляция в современных движках (V8, SpiderMonkey, JavaScriptCore).

Пример кода

// Первая программа
const greeting = 'Hello, World!';
console.log(greeting);
