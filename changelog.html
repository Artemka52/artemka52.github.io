История версий ECMAScript

ES2015 (ES6) — 2015

Самое крупное обновление в истории языка.

  • let и const
  • Стрелочные функции =>
  • Классы
  • Промисы
  • Модули (import/export)
  • Шаблонные строки
  • Деструктуризация
  • Параметры по умолчанию, rest, spread
  • Symbol, Map, Set, WeakMap, WeakSet
  • Итераторы и for...of

ES2016 - 2016

  • Оператор возведения в степень **
  • Array.prototype.includes()

ES2017 - 2017

  • async/await
  • Object.values(), Object.entries()
  • Разделители разрядов: 1_000_000
  • String.prototype.padStart/padEnd

ES2018 - 2018

  • Асинхронные итераторы for await...of
  • Rest/Spread для объектов
  • Именованные группы в регулярках
  • Promise.prototype.finally()

ES2019 - 2019

  • Array.prototype.flat(), flatMap()
  • Object.fromEntries()
  • String.prototype.trimStart/trimEnd
  • Опциональный catch {}

ES2020 - 2020

  • BigInt
  • Nullish coalescing ??
  • Опциональная цепочка ?.
  • Promise.allSettled()
  • globalThis
  • Динамический import()

ES2021 - 2021

  • String.prototype.replaceAll()
  • Promise.any()
  • Логические операторы присваивания ||=, &&=, ??=
  • WeakRef

ES2022 - 2022

  • Top-level await
  • Приватные поля классов #field
  • Статические блоки инициализации
  • Object.hasOwn()
  • .at() для массивов и строк
  • Error.prototype.cause

ES2023 - 2023

  • Методы массивов с копированием: toSorted(), toReversed(), toSpliced(), with()
  • findLast(), findLastIndex()

ES2024 - 2024

  • Object.groupBy(), Map.groupBy()
  • Promise.withResolvers()
  • Флаг /v для регулярок

Полный список - на tc39.es/ecma262.
