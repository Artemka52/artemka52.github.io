Часто задаваемые вопросы

Чем JavaScript отличается от Java?

Это разные языки. Общее только название. Java - компилируемый строго типизированный язык; JavaScript - интерпретируемый динамический.

Что такое ECMAScript?

Стандарт, описывающий язык. JavaScript - его реализация. Актуальная версия - ECMAScript 2026 (ES2026). Обновления выходят ежегодно с 2015 года.

let, const или var?

  • const - по умолчанию.
  • let - если значение будет переприсваиваться.
  • var - не использовать в новом коде.

Строгое равенство === и нестрогое ==?

Всегда используйте === и !==. Исключение - value == null (ловит одновременно null и undefined).

Что такое hoisting?

Механизм поднятия объявлений в начало области видимости. var и function declaration поднимаются, let и const - нет.

Почему typeof null === 'object'?

Историческая ошибка первых версий JavaScript. Исправить нельзя - сломает обратную совместимость. Проверяйте value === null.

Callback, Promise или async/await?

По умолчанию — async/await. Для параллельных операций - Promise.all / allSettled.

Что такое Event Loop?

Механизм, позволяющий однопоточному JavaScript выполнять асинхронные операции. Подробнее — в разделе Асинхронность.

JavaScript и Node.js - это одно и то же?

Нет. JavaScript - язык. Node.js - среда выполнения на движке V8.
