Асинхронность в JavaScript

JavaScript — однопоточный язык. Всё асинхронное выполняется через Event Loop.

Event Loop в двух словах

  1. Стек вызовов выполняет синхронный код.
  2. Асинхронные операции уходят в Web API / libuv.
  3. Их колбэки попадают в очередь макротасок или микротасок.
  4. Когда стек пуст, Event Loop забирает задачи из очередей.
console.log('1');
setTimeout(() => console.log('2'), 0);
Promise.resolve().then(() => console.log('3'));
console.log('4');

// Вывод: 1, 4, 3, 2
// Микротаски (Promise) раньше макротасок (setTimeout)

Три подхода

1. Колбэки

setTimeout(() => {
  console.log('Прошла секунда');
}, 1000);

2. Промисы

fetch('/api/users')
  .then(res => res.json())
  .then(users => console.log(users))
  .catch(err => console.error(err));

3. async / await

async function loadUsers() {
  try {
    const res = await fetch('/api/users');
    const users = await res.json();
    console.log(users);
  } catch (err) {
    console.error(err);
  }
}

Что выбрать

  • Простой таймер → setTimeout / setInterval
  • Один запрос → async/await
  • Параллельные запросы → Promise.all / allSettled
  • Поток событий → addEventListener
