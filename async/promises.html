Промисы (Promises)

Promise — объект, представляющий результат асинхронной операции. Три состояния:

  • pending — ожидание
  • fulfilled — успешно выполнено
  • rejected — отклонено

Создание

const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    const success = true;
    if (success) resolve('Готово!');
    else reject(new Error('Ошибка'));
  }, 1000);
});

Потребление

promise
  .then(value => console.log(value))
  .catch(error => console.error(error))
  .finally(() => console.log('Завершено'));

Цепочки

fetch('/api/user/1')
  .then(res => res.json())
  .then(user => fetch(`/api/posts?user=${user.id}`))
  .then(res => res.json())
  .then(posts => console.log(posts))
  .catch(err => console.error(err));

Promise.all — параллельно, ждать всех

const [users, posts, comments] = await Promise.all([
  fetch('/api/users').then(r => r.json()),
  fetch('/api/posts').then(r => r.json()),
  fetch('/api/comments').then(r => r.json()),
]);

Promise.allSettled — не падает при ошибке

const results = await Promise.allSettled([
  fetch('/ok'),
  fetch('/fail'),
]);
// [{ status: 'fulfilled', value }, { status: 'rejected', reason }]

Promise.race — первый завершившийся

const fastest = await Promise.race([
  fetch('/server-a'),
  fetch('/server-b'),
]);

Promise.any — первый успешный

const firstOk = await Promise.any([
  fetch('/mirror-1'),
  fetch('/mirror-2'),
  fetch('/mirror-3'),
]);

Статические методы

  • Promise.resolve(v) — выполненный промис
  • Promise.reject(e) — отклонённый промис
  • Promise.all([...]) — ждёт все, падает при первой ошибке
  • Promise.allSettled([...]) — ждёт все, возвращает статусы
  • Promise.race([...]) — первый завершившийся
  • Promise.any([...]) — первый успешный
