Начало работы

Где запускать JavaScript

  1. Браузер - консоль DevTools (F12) или тег <script>.
  2. Node.js - серверная среда выполнения.
  3. Онлайн-песочницы - CodePen, JSFiddle, Replit.

Установка Node.js

Скачайте LTS-версию с nodejs.org. Проверьте установку: 

node --version
// v20.11.0
npm --version
// 10.2.4

Первая программа

Создайте файл hello.js:

const name = 'Мир';
console.log(`Привет, ${name}!`);

function greet(who) {
  return `Hello, ${who}!`;
}

console.log(greet('JavaScript'));

Запустите командой:

node hello.js

Подключение к HTML

<!DOCTYPE html>
<html>
  <body>
    <h1>Моя страница</h1>
    <script>
      document.querySelector('h1').textContent = 'Изменено из JS';
    </script>
  </body>
</html>

Полезные инструменты

  • VS Code - редактор.
  • Node.js + npm - среда и пакеты.
  • ESLint - проверка кода.
  • Prettier - автоформатирование.
  • Vite / Webpack - сборка.
