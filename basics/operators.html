Операторы

Арифметические

10 + 3    // 13
10 - 3    // 7
10 * 3    // 30
10 / 3    // 3.3333...
10 % 3    // 1  (остаток)
10 ** 3   // 1000 (степень)

Присваивание

let x = 5;
x += 2;   // 7
x -= 1;   // 6
x *= 2;   // 12
x /= 3;   // 4
x **= 2;  // 16
x ??= 10; // только если x был null/undefined

Сравнение

5 > 3      // true
5 < 3      // false
5 >= 5     // true
5 == '5'   // true
5 === '5'  // false
5 !== '5'  // true

Логические

true && false      // false
true || false      // true
!true              // false

const name = userInput || 'Аноним';
const city = user && user.address && user.address.city;
const port = config.port ?? 3000;

Опциональная цепочка

const user = { profile: { name: 'Alex' } };

console.log(user?.profile?.name);   // 'Alex'
console.log(user?.settings?.theme); // undefined

Тернарный оператор

const msg = count > 0 ? 'Есть' : 'Пусто';

Spread и Rest

// Spread
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];       // [1, 2, 3, 4]
const obj2 = { ...{ a: 1 }, b: 2 }; // { a: 1, b: 2 }

// Rest
function sum(...nums) {
  return nums.reduce((s, n) => s + n, 0);
}
sum(1, 2, 3, 4); // 10
