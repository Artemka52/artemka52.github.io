Типы данных

В JavaScript 8 типов: 7 примитивов и object.

Примитивы

  • number — 42, 3.14, NaN, Infinity
  • bigint — 9007199254740993n
  • string — 'hi', "hi", `hi`
  • boolean — true / false
  • undefined — значение не задано
  • null — намеренное отсутствие значения
  • symbol — Symbol('id')

Object

Всё остальное - объекты: массивы, функции, даты, Map, Set.

const obj = { a: 1 };
const arr = [1, 2, 3];
const fn  = () => {};

console.log(typeof obj);  // 'object'
console.log(typeof arr);  // 'object'
console.log(typeof fn);   // 'function'

Проверка типа: typeof

typeof 42           // 'number'
typeof 'hello'      // 'string'
typeof true         // 'boolean'
typeof undefined    // 'undefined'
typeof null         // 'object' — историческая ошибка
typeof {}           // 'object'
typeof []           // 'object'
typeof function(){} // 'function'

Приведение типов

// Явное
Number('42')     // 42
String(42)       // '42'
Boolean(0)       // false

// Неявное
'5' + 3          // '53'
'5' - 3          // 2
+'5'             // 5
!!'abc'          // true

Строгое и нестрогое равенство

1 == '1'    // true   (приведение)
1 === '1'   // false  (без приведения — рекомендуемое)
null == undefined   // true
null === undefined  // false
NaN === NaN         // false

Всегда используйте === и !==.
