Синтаксис JavaScript

Переменные

var a = 1;     // устаревшее, функциональная область видимости
let b = 2;     // изменяемая, блочная область
const c = 3;   // неизменяемая привязка

Используйте const по умолчанию, let - когда значение будет меняться. var - только для legacy-кода.

Строгий режим

'use strict';
x = 10; // ReferenceError

Условные конструкции

const age = 20;

if (age >= 18) {
  console.log('Совершеннолетний');
} else if (age >= 14) {
  console.log('Подросток');
} else {
  console.log('Ребёнок');
}

const status = age >= 18 ? 'adult' : 'minor';

Циклы

for (let i = 0; i < 3; i++) console.log(i);

let j = 0;
while (j < 3) { console.log(j); j++; }

for (const item of [10, 20, 30]) console.log(item);
for (const key in { a: 1, b: 2 }) console.log(key);

Правила оформления

  • Отступ - 2 или 4 пробела, единообразно.
  • Имена переменных - camelCase.
  • Классы - PascalCase.
  • Константы - UPPER_SNAKE_CASE.
